# dsh-qq-whale · 大肥鱼

住在 DSH 里的 QQ 伙伴：有自己的偏好、记忆与情绪，能聊天、看图、听语音，也能用浏览器和本地工具帮忙办事。

## 下载和使用

从本仓库的 **Releases** 下载 `dsh-qq-whale-0.21.2-windows-x64.zip` 并完整解压。这个安装包包含运行依赖，模型和 QQ 组件按需准备，不需要全部下载。

1. 在 DSH 插件管理中从本地导入解压后的插件目录，启用大肥鱼。已有旧版大肥鱼时先停用旧版，避免重复加载。
2. 打开大肥鱼，首次进入会显示「工具准备」。勾选需要的工具，点击「一键准备所选工具」。准备期间保持 DSH 打开；失败项会显示原因，可重试。
3. 打开「QQ」，点击「扫码登录 QQ」，使用给大肥鱼准备的 QQ 账号扫码并在手机确认。二维码显示在插件内，后台日志窗口会隐藏。
4. 填写自己的「主号 QQ」并保存连接，作为她回复的对象。首次绑定前不回复陌生联系人。之后打开 DSH 自动连接；登录失效时重新扫码。
5. 需要她操作网站时，去「平台登录」登录相应账号。网站与 QQ 的登录资料只保存在当前电脑。

自动准备目前支持 **Windows x64**。安装包必须完整解压，不要在 ZIP 中直接运行。如果 DSH 的版本不支持导入本地目录，可按该版本插件管理提供的本地安装方式选择此目录的 `package.json`；源码用户先运行 `INSTALL.cmd` 准备依赖。

## 选择哪些工具

基础聊天、性格、情绪和关键词记忆使用 DSH 已配置的对话模型。其他能力都可单独选，详细用途、大小和官方来源见 [TOOLS.md](TOOLS.md)，插件内也提供同一份选择列表。

- **QQ**：NapCat 与独立便携 QQ，自动下载并解包到插件个人数据目录，不运行 QQ 安装向导，不修改系统 QQ。
- **网页操作**：Playwright 与独立浏览器；已有可用 Chrome/Edge 时可以复用程序，登录档案仍独立。
- **图片与表情包**：本机 Ollama + Qwen3-VL 2B；对动态图片抽样，识别可能有误。
- **语义记忆**：本机 BGE-M3；关键词检索始终可用。记忆随时间衰减，被真实回忆强化；重要事实和纠错有单独处理。
- **听与说**：SenseVoice Small INT8 听语音，Breeze-TTS-2（本机 Vulkan）说中文，音色可按描述定制；语音文字只在本机处理。
- **剪辑**：本地 FFmpeg，支持裁剪、拼接、字幕、配乐、封面和音轨。
- **操作节奏**：网页操作默认每小时最多 150 次、动作间隔 ≥0.7 秒；「发布 / 发送 / 支付 / 删除」默认要确认，且每天最多 10 次。这些是插件自己加的防封号总闸，不是浏览器限制，换 Chrome / Edge 也绕不开。确实要放宽时用 `DSH_MENTOR_HOURLY_LIMIT`（每小时上限）和 `DSH_MENTOR_DAILY_CONFIRM`（每日不可逆动作）调整，放宽越多越容易被平台风控盯上。

## 生图、视频与网站

已列入豆包、即梦、可灵、海螺、Vidu、通义万相和剪映的官方入口，由浏览器查看当前页面、登录和操作。网站无需全部注册；使用者自行选择账号与服务。网页入口、额度、付费与验证码以平台实际界面为准。剪映若仅提供客户端下载，应使用客户端或本地 FFmpeg；不能把官网首页当作在线剪辑器。

这些是浏览器接入入口，并不保证各网站当前账号的生图、视频生成和剪辑都已完成实测。下载真实成片后才可交付；遇到验证码或登录失效需要本人处理。视频页面只抽样画面与可取文字，不冒充完整观看。

支持独立 QQ 空间登录、说说草稿与发布结果检查，以及挑着回复别人在说说下的评论（每天可设上限）。自动发表和自动回复需要在设置中启用；否则只留草稿、不主动回。抖音账号、相互关注及抖音私信视频分享仍需后续对接，当前版本不宣称已经支持自动私信分享。

## 数据与兼容

插件包名是 `dsh-qq-whale`。为兼容旧版记忆，内部实例 ID、界面模块 ID 和接口前缀继续使用 `dsh-mentor`。默认个人数据保存在 `~/.dsh/storages/dsh-mentor/`，源码和发布包中不包含账号、聊天记录、Cookie、令牌、课表或模型文件。请勿同时加载新旧两套实例。

图片和语音只交给本机处理。DSH 的文字对话仍使用使用者在 DSH 中选择的模型；让她调用网站创作时，提示词和参考素材会提交给所选网站。组件下载尊重环境代理与 Windows 系统代理；可用 `DSH_QQ_WHALE_DOWNLOAD_PROXY` 指定下载代理，它不用于聊天媒体识别。

已有 NapCat 可用 `DSH_QQ_WHALE_NAPCAT_DIR` 指定目录；原 `DSH_MENTOR_NAPCAT_DIR` 仍兼容。远程 OneBot 可在高级连接设置中配置；自动准备和扫码面向本机运行环境。

## 开发验证

```sh
npm ci
npm run verify:release
npm run verify:upgrade
```

`verify:integration` 需要可用的浏览器和 FFmpeg；`verify:qq` 需要本地语音与视觉模型，使用隔离的假 QQ 服务，不向真实联系人发消息。`verify:memory` 需要本机 Ollama 的 BGE-M3。工具下载与首次安装还受网络和上游版本兼容性影响。

插件使用 MIT 许可；QQ、NapCat、浏览器、模型、语音数据、FFmpeg 和各网站分别适用自己的许可及条款。
