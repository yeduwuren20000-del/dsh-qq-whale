# dsh-qq-whale · 大肥鱼

DSH 里的 QQ 伙伴：记忆、性格、情绪、本地媒体理解、浏览器操作、创作与唱歌。

## 第一次使用

先看 [完整初始化教程](GETTING_STARTED.md)，需要语音时看 [语音与唱歌安装说明](VOICE_SETUP.md)。插件右上角也有始终可打开的「使用教程」。

1. 从 [Releases](https://github.com/yeduwuren20000-del/dsh-qq-whale/releases/latest) 下载完整 Windows x64 ZIP 并解压，在 DSH 插件管理导入并启用。不要同时加载新旧两套。
2. 在 DSH 配好聊天模型，首次打开选择初始性格，先确认能正常聊天。
3. 在「工具准备」选择 QQ 和所需能力。自动准备支持 Windows x64；语音大模型及唱歌方案按说明单独安装，不会全部自动下载。
4. 在「QQ」扫码登录伙伴的独立 QQ 账号，用手机确认；「主号 QQ」填写你平时的号码并保存。之后打开 DSH 自动连接，后台日志隐藏。
5. 在「平台登录」登录需要的网站。QQ 空间需另扫码；自动发表须另开启，不开启只留草稿。

源码下载不包含运行依赖，可先运行 INSTALL.cmd。完整 Release 安装包已经包含 Node 运行依赖；不要在 ZIP 内直接运行。

## 为什么重装后还有原来的日记？

程序与本机档案分开保存。重装、升级会继续读取当前电脑的旧日记、记忆与设置，并不会自动清空。它们没有因此进入 GitHub 安装包。新电脑或全新档案从空白开始。

为兼容旧版，内部实例 ID、接口前缀及默认档案目录仍为 dsh-mentor，默认位置 `~/.dsh/storages/dsh-mentor/`。不要为重看教程删除档案，也不要将整个 .dsh、登录资料或音色参考打包上传。公开安装包不含作者的日记、账号、聊天、课表、Cookie、声模和训练素材。

## 按需选择工具

基础聊天、性格、情绪与关键词记忆使用 DSH 配置的对话模型。可选工具包括 NapCat/便携 QQ、独立 Playwright 浏览器、Ollama/Qwen3-VL 识图、BGE-M3 语义记忆、SenseVoice 听写、Breeze/CosyVoice 说话、Seed-VC/RVC 唱歌、Demucs 人声分离、FFmpeg/Auto-Editor 剪辑及 Anime.js HTML 动画。

官方来源及准备方式见 [TOOLS.md](TOOLS.md)、[VOICE_SETUP.md](VOICE_SETUP.md)、[创作工具说明](CREATIVE_TOOLS.md)。工具准备面板也会展示可选方案。只下载自己需要的模型；网页创作使用自己的账号，额度和费用以网站为准。

豆包、即梦、可灵、海螺、Vidu、通义万相与剪映提供浏览器入口，不保证每个平台当前页面都已完成端到端实测。实际生成并下载成片后才交付；验证码由本人处理。抖音私信视频分享仍未作为已完成能力提供。

## 语音与用量

日常使用较快的 Breeze，CosyVoice 的细腻语气作为可选项。固定音色允许情绪改变语气，不随机更换说话人。Seed-VC 唱歌先分离人声，保留旋律，再混回原伴奏；长歌通过 QQ 语音分段，成功后不先发重复文字。按需轮流使用显卡，减少资源冲突。

日常只携带少量常用工具，其余按需启用。记忆采用遗忘曲线、重要度和真实召回强化，不额外逐轮调用模型反思。她自己的偏好与用户事实分开保存；主动交流、点赞和空间行为见 [SOCIAL_BEHAVIOR.md](SOCIAL_BEHAVIOR.md)。

图片和语音默认在本机处理；共享调试服务器不是默认常驻后端。文字对话使用你在 DSH 选择的模型；网站创作会向选定网站提交提示词和参考素材。
